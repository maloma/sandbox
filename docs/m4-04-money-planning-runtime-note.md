# M4-04 Money Planning Runtime Note

This bounded runtime package implements the accepted FamilyPilot decisions for:

- cash and cashless money locations;
- purpose allocations without capital double counting;
- general capital savings rule triggered by actual received income;
- confirmation of planned savings transfers;
- neutral balance adjustments;
- birthday planning;
- hybrid gift-fund contribution planning.

No bank synchronization, payment execution, authentication, production deployment or automatic financial action is included.
